The Smart Museum Artifact Conservation System protects valuable historical artifacts by monitoring and controlling the environment inside a conservation chamber.


### System Operation

When the chamber is powered on, the system performs a self-check of sensors and environmental-control devices.

After a successful self-check, the system enters monitoring mode.

When an artifact is placed inside, the system records its identification information and required environmental limits.

The system then monitors and controls the chamber environment.
